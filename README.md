## 真实的缺点：这几个限制买之前该知道

第三方评测里反复提到的抱怨，集中在下面几点。

macOS 大版本更新之后，少数用户会出现充电行为不对的情况。这不是黑稿，开发者自己的 FAQ 就承认过，通常等一个版本更新修好。赶在新系统刚发布那几天装，遇到问题的概率会高一点。

睡眠和关机状态下不保证执行。免费版明确不行，Pro 也只是“尽量”，Apple 芯片的机器关机时不一定能强制住上限。指望它 24 小时守着电池的，预期要放低。

Pro 至少每 30 天要联网校验一次授权，离线超过 30 天会退回免费版。常年不联网的机器，或者你打算把它装在一台当备用机的老 Mac 上，这点要提前知道。

“Lifetime”这三个字不是商店的承诺。购买须知里写得很直白，这类表述来自开发者，未来的更新和维护由开发者负责，商店不为它兜底。买断买的是当前版本加开发者的更新意愿，不是一纸永久合同。

最后一条，AlDente 不保证你的电池健康变好。它能做的是减少电池长时间处于满电的时间，苹果自己也承认充电习惯会影响化学老化，但具体到你这台机器的健康度百分比，没有任何工具能打包票。
